## ข้อที่ 1 การกลับลำดับสตริง (Reverse String)

# อัลกอริทึมที่ 1 : Recursive Algorithm

## แนวคิด

ใช้อัลกอริทึมแบบเวียนเกิด (Recursion) โดยนำตัวอักษรตัวสุดท้ายของสตริงมาต่อกับผลลัพธ์ของการเรียกเมธอดกับสตริงที่เหลือ

## Pseudocode

```
ReverseRecursive(s)

ถ้าความยาวของ s <= 1
    คืนค่า s

คืนค่า
ตัวอักษรตัวสุดท้ายของ s
+
ReverseRecursive(สตริงที่เหลือ)
```

### ตัวอย่างผลลัพธ์

Input

```
hello
```

Output

```
olleh
```
